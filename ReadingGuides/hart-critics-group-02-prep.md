# 제2조 사전 가이드: 재량과 난해한 사건

## 고정 범위

Ronald Dworkin, *Taking Rights Seriously* (1977), pp. 31-39, 81-86.

- “Discretion”
- “Hard Cases”의 도입과 “The Rights Thesis” 시작 부분

## 이 범위의 역할

공통 필독은 원칙이 법적 판단에서 작동한다는 사례를 제시한다. 이 범위는 그 관찰이 왜 판사의 재량과 당사자의 기존 권리 문제로 이어지는지 보여준다. 핵심은 “판사가 판단한다”는 평범한 뜻의 재량과, 법적 기준이 어느 결과도 요구하지 않는다는 강한 뜻의 재량을 분리하는 데 있다.

## 이 독서가 맞서는 압박

규칙이 명백한 답을 주지 않을 때 판사는 기존 법적 권리를 확인하는가, 아니면 새 권리를 소급적으로 창출하는가? 결정이 어렵다는 사실은 법적으로 옳은 답이 존재하지 않는다는 결론을 정당화하는가?

## 읽기 순서

1. pp. 31-32에서 “재량”이 어떤 일상적 비유로 설명되는지 표시한다.
2. pp. 32-34에서 두 약한 의미와 강한 의미를 구별한다.
3. pp. 34-36에서 법실증주의가 어느 의미의 재량을 필요로 하는지 확인한다.
4. pp. 36-39에서 원칙이 규칙의 변경과 구속력에 어떤 역할을 하는지 추적한다.
5. pp. 81-86에서 난해한 사건의 판사를 입법자처럼 보는 설명에 제기되는 두 제도적 반론을 찾는다.

## 반드시 구별할 것

| 구별 | 확인할 질문 |
| --- | --- |
| 판단이 필요한 재량 / 결정이 최종적인 재량 / 기준이 없는 재량 | 각 문장의 “재량”은 셋 중 어느 뜻인가? |
| 결정절차의 부재 / 옳은 답의 부재 | 전자에서 후자가 따라오는가? |
| 원칙이 결과를 자동 결정하지 않음 / 원칙이 판사를 구속하지 않음 | 무게를 가진 이유도 책무를 만들 수 있는가? |
| 정책 / 원칙 | 판결 이유는 공동체 전체의 목표와 당사자의 기존 권리 중 무엇에 기대는가? |
| 법 발견 / 법창출 | 소급성과 민주적 책임 문제는 어느 설명에서 더 커지는가? |

## 원문에서 직접 찾을 것

- 코치·심판 등의 비유가 재량의 여러 의미를 나누는 방식
- 법실증주의자가 강한 재량을 주장하려면 추가로 입증해야 하는 전제
- 원칙이 기존 규칙을 바꾸는 이유와 기존 규칙을 지키는 이유로 모두 사용되는 대목
- 판사를 대리 입법자로 볼 때 생기는 민주적 책임과 소급성의 문제
- “기존 권리”라는 표현이 사실상 이미 결론을 전제하는지 시험할 대목

## 1쪽 브리프의 초점

원문의 “discretion”마다 약한 의미 1, 약한 의미 2, 강한 의미를 표시한 뒤, 드워킨이 어느 전환을 문제 삼는지 한 개의 추론으로 재구성한다. 이어 난해한 사건에서 그 전환이 왜 제도적 정당화 문제를 낳는지 연결한다.

## 피해야 할 성급한 결론

- 드워킨이 모든 의미의 재량을 부정한다고 쓰지 않는다.
- 강한 재량을 판사의 자의나 개인 취향과 동일시하지 않는다.
- 원칙이 존재하면 모든 사건에 유일한 답이 자동으로 나온다고 단정하지 않는다.
- 원칙에 의한 판결이면 소급성 문제가 설명 없이 사라진다고 보지 않는다.

## Postscript로 가져갈 질문

1. 하트의 법창출적 재량은 드워킨의 세 의미 중 어디에 해당하는가?
2. 하트가 재량은 자의적이지 않다고 답하면 기존 권리 비판에도 답한 것인가?
3. 법이 미확정이라는 진술은 인식의 한계인가, 법의 존재에 관한 진술인가?
