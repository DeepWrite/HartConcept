# 공통 용어 지도와 발표 전 질문

이 문서는 장별 발표 전에 공개해도 되는 공통 용어 지도다. 각 조는 자기 장에서 이 용어들이 어떤 의미로 쓰이는지 본문 근거를 찾아야 한다.

용어의 한국어 대응어만 확인하는 데서 멈추지 말고, 그 용어가 해당 장에서 어떤 구별을 만들고 어떤 반론을 차단하며 어떤 결론을 가능하게 하는지 함께 추적해야 한다.

## 기본 구조 용어

| English | Korean | 확인 질문 |
| --- | --- | --- |
| `law` | `법` | 하트가 여기서 `법`을 정의하려 하는가, 개념을 해명하려 하는가? |
| `legal system` | `법체계` | 이 장에서 법과 법체계가 구별되는가? |
| `rule` | `규칙` | 규칙은 명령, 습관, 예측, 도덕과 어떻게 구별되는가? |
| `habit` | `습관` | 반복적 일양성과 규칙 수용은 어떻게 다른가? |
| `obligation`, `duty` | `의무`, `책무` | 의무가 단순한 처벌 가능성으로 환원되는가? |
| `internal point of view` | `내부 관점` | 참여자는 규칙을 어떤 태도로 받아들이는가? |
| `external point of view` | `외부 관점` | 관찰자는 무엇을 볼 수 있고 무엇을 놓치기 쉬운가? |

## 법체계의 요소

| English | Korean | 확인 질문 |
| --- | --- | --- |
| `primary rules` | `일차 규칙들` | 이 장에서 행위 의무를 직접 부과하는 규칙은 무엇인가? |
| `secondary rules` | `이차 규칙들` | 승인, 변경, 재판 규칙이 어떤 결함을 고치는가? |
| `rule of recognition` | `승인 규칙` | 법적 유효성 기준은 어디서 오는가? |
| `rule of change` | `변경 규칙` | 정태성을 어떻게 해소하는가? |
| `rule of adjudication` | `재판 규칙` | 위반 여부의 불확실성을 어떻게 해소하는가? |
| `legal validity` | `법적 유효성` | 유효성과 도덕적 정당성은 구별되는가? |

## 도덕, 정의, 실증주의

| English | Korean | 확인 질문 |
| --- | --- | --- |
| `morality` | `도덕`, `도덕규범` | 법과 도덕의 어떤 관계가 문제인가? |
| `justice` | `정의` | 정의는 도덕 전체인가, 도덕의 한 부문인가? |
| `legal positivism` | `법실증주의` | 하트가 방어하는 실증주의 명제는 정확히 무엇인가? |
| `natural law` | `자연법` | 하트는 자연법을 전부 거부하는가, 일부를 보존하는가? |
| `legality` | `법다움` | Fuller식 논점과 하트의 제한적 수용을 구별할 수 있는가? |
| `validity` | `유효성` | 유효한 법이 사악할 수 있는가? |

## 후기와 드워킨 논쟁

| English | Korean | 확인 질문 |
| --- | --- | --- |
| `interpretive` | `해석적` | 드워킨의 법이론은 무엇을 해석하려 하는가? |
| `descriptive` | `기술적` | 하트의 기술은 평가를 배제하는가, 평가를 기술할 수 있는가? |
| `semantic sting` | `의미론적 독침` | 하트가 정말 의미론적 이론을 가졌는가? |
| `soft positivism` | `연성 실증주의` | 도덕 기준이 승인 규칙에 편입될 수 있는가? |
| `principle` | `원칙` | 원칙은 규칙과 종류가 다른가, 정도가 다른가? |
| `discretion` | `재량` | 어려운 사례에서 판사는 법을 적용하는가, 만드는가? |

## 발표 전 공통 질문

1. 이 장에서 하트가 가장 먼저 제거하려는 오해는 무엇인가?
2. 하트의 핵심 구별은 기존 이론의 어떤 단순화를 겨냥하는가?
3. 이 장의 사례들은 단순 예시인가, 반례인가, 개념 실험인가?
4. 이 장에서 `법`과 `도덕`은 어떤 방식으로 가까워지고 어떤 방식으로 멀어지는가?
5. 이 장의 결론이 제5장 `일차 규칙과 이차 규칙의 결합`으로 되돌아가는가?
