# Dworkin 핵심 단행본 장별 지도

하트 비판의 출발점과 드워킨의 성숙한 해석주의를 한 흐름으로 읽기 위한 1차 핵심군은
*Taking Rights Seriously*와 *Law's Empire*입니다. 이 페이지는 각 장이
책 전체에서 맡는 기능을 표시하는 지도이며, 원문을 대신하는 요약본은 아닙니다.

> **판본 주의.** *Taking Rights Seriously*의 Bloomsbury 전자책 내장 쪽수와
> 1977/1978 Harvard 인쇄본의 고전적 인용 쪽수는 서로 다르고, 책 전체에 적용되는
> 단순 오프셋도 없습니다. 수업 범위와 인용에는 반드시 판본을 함께 표시합니다.

## Taking Rights Seriously

| 장 | 책에서 맡는 기능 | 핵심 연결점 |
| --- | --- | --- |
| 서론 | 개념적 법이론과 규범적 법이론을 결합하는 일반 이론의 구도를 세우고, 권리를 집단적 목표에 대한 개인의 으뜸패로 제시한다. | 배경적 권리·제도적 권리·법적 권리, 동등한 관심과 존중 |
| 제1장 법리학 | 법도그마틱·사회학·수단-목적 분석만으로는 법리학의 도덕적 원칙 문제를 포착할 수 없다고 논증한다. | 하트의 성취와 일상언어 분석의 한계 |
| 제2장 규칙의 모델 I | 계보로 식별되는 규칙만을 법으로 보면 난해한 사안에서 작동하는 원칙을 법 밖으로 밀어내게 된다는 압박을 제기한다. | 규칙·원칙·정책, 무게, 강한 재량, 승인 규칙 |
| 제3장 규칙의 모델 II | 사회 규칙과 승인 규칙을 수정해 원칙을 수용할 수 있는지, 그렇게 수정하면 법실증주의의 구조가 유지되는지 검토한다. | 사회 규칙, 제도적 뒷받침, 하트와의 실제 의견불일치 |
| 제4장 난해한 사안들 | 명시적 규칙이 소진된 뒤 판사가 새 법을 만드는 것이 아니라 제도적 권리를 판단한다는 권리 테제를 전개한다. | 원칙 논증과 정책 논증, 헤라클레스, 제도사 |
| 제5장 헌법 사건들 | 사법적극주의와 사법자제라는 거친 대립을 원칙에 기초한 헌법재판의 문제로 재구성한다. | 사법심사, 민주주의, 권리 테제 |
| 제6장 정의와 권리들 | 입법적 권리들의 토대를 롤스와 대화하면서 동등한 관심과 존중을 받을 권리에서 찾는다. | 정의, 평등, 최소수혜자, 권리의 토대 |
| 제7장 권리를 진지하게 받아들이기 | 국가가 권리를 단순한 복지 계산의 한 항목으로 취급할 수 없을 때 시민과 정부에 어떤 실천적 결과가 생기는지 밝힌다. | 시민의 권리, 법 위반, 논쟁적인 권리 |
| 제8장 시민불복종 | 헌법적 권리가 불확실할 때 시민과 공무담당자가 어떻게 행위해야 하는지 묻는다. | 진지한 법적 의견불일치, 기소와 집행, 공적 책임 |
| 제9장 역차별 | 동등한 관심과 존중이라는 평등 구상을 인종차별과 적극적 우대조치에 적용한다. | 평등보호, 형식적 대칭, 역차별 |
| 제10장 자유와 도덕주의 | 사회가 자신의 도덕을 법으로 강제할 권리를 갖는다는 데블린식 논증이 진정한 도덕적 입장인지 검토한다. | 법적 도덕주의, 개인의 도덕적 독립, 음란물 |
| 제11장 자유와 자유주의 | 자유주의를 무제한적 자유나 무내용적 중립성으로 정의하는 대신 평등의 도덕적 토대에서 재구성한다. | 자유주의와 평등, 제12장의 준비 |
| 제12장 우리에게는 어떤 권리들이 있는가? | 일반적 자유권이라는 관념을 비판하면서도 특정 자유들에 대한 권리를 동등한 관심과 존중에서 도출한다. | 자유와 평등, 권리의 으뜸패 구조 |
| 제13장 권리는 논란의 대상이 될 수 있는가? | 기계적 증명 절차가 없다는 사실에서 논쟁적인 권리가 존재하지 않는다는 결론은 나오지 않는다고 논증한다. | 객관성, 논증가능성, 정답 없음의 주장 |
| 부록 비판자들에게 답함 | 하트, 그리너월트, 먼저(Munzer), 리처즈, 소퍼, 니켈, 매키, 라즈의 비판을 상대로 책의 주장을 조정하고 방어한다. | 초기 권리론에서 성숙한 해석주의로 넘어가는 연결부 |

## Law's Empire

| 장 | 책에서 맡는 기능 | 핵심 연결점 |
| --- | --- | --- |
| 서문 | 법리학·재판·통합성·공동체·우애를 하나의 해석적 이론으로 묶으려는 책의 야심을 밝힌다. | 정답 문제, 논증과 알고리즘의 차이 |
| 제1장 법이란 무엇인가? | 법률가들은 법의 근거들 자체를 두고 이론적으로 의견을 달리하며, 명백한 사실 관점과 의미론 이론은 이를 충분히 설명하지 못한다고 논증한다. | *Riggs*, 달팽이 피라미 사건, *McLoughlin*, *Brown* |
| 제2장 해석적 개념들 | 공유 기준이 없으면 진정한 의견불일치도 없다는 의미론적 독침을 구성적 해석으로 극복한다. | 예절, 부합과 정당화, 개념과 구상, 내적·외적 회의주의 |
| 제3장 법리학을 다시 살펴보기 | 법을 해석적 개념으로 파악하고, 법적 실천에 경쟁적으로 부합하고 이를 정당화하는 법구상들을 제시한다. | 관행주의·실용주의·통합성, 악한 법체계, 법의 근거들과 힘 |
| 제4장 관행주의 | 공정한 사전고지와 규율된 강제를 약속하는 관행주의가 실제 법적 실천에 충분히 부합하고 이를 정당화하는지 시험한다. | 엄격한·완화된 관행주의, 관행과 합의, 기대 보호와 조정 |
| 제5장 실용주의와 인격화 | 최선의 미래를 위해 진정한 법적 권리를 부정하는 실용주의가 법적 실천과 정치적 책임을 설명할 수 있는지 검토한다. | 마치 있는 것 같은 권리, 장래적 규칙 제정, 공동체의 인격화 |
| 제6장 통합성 | 통합성이 왜 독립된 정치적 미덕이며, 도덕적 의견불일치 속에서 정치적 책무와 정당성을 어떻게 기초짓는지 논증한다. | 바둑판식 타협, 결사적 책무, 원칙 공동체 |
| 제7장 법에서의 통합성 | 통합성을 과거에 대한 충실성과 도덕적 정당화를 함께 요구하는 실제 재판 방법으로 전환한다. | 연쇄소설, 헤라클레스, 부합과 정당화, 정신적 손해, 법비판연구 |
| 제8장 보통법 | 사고법에 대한 경제적·공리주의적·평등주의적 해석을 경쟁시켜 통합성의 재판 방법을 시험한다. | 코즈 정리, 부의 극대화, 합리인, 기여과실 |
| 제9장 제정법 | 집단적 입법의도를 이미 완성된 정신상태로 볼 수 없다는 압박 아래 문언·연혁·목적·원칙을 통합하는 해석을 제시한다. | 발화자 의미, 입법자의 신념, 입법연혁, 명백한 문언 |
| 제10장 헌법 | 역사주의·소극주의·보수/진보의 통상적 표지가 헌법해석을 정당화하기에 충분한지 검토한다. | *Brown*, *Bakke*, 인종적 평등, 다수결, 헤라클레스 비판 |
| 제11장 법 너머의 법 | 현재의 법과 더 순수한 법의 가능성을 구별하면서도 통합성과 제도사에 대한 충실성을 유지하는 방식을 설명한다. | 포괄적·순수한 통합성, 법의 꿈들, 해석적 태도로서의 법 |
