# Postscript 발표 전 브리프

이 페이지는 결론을 대신하는 요약본이 아니라, 후기에서 비판과 응답의 위치를 찾기 위한 사전 독해표다.

## 이 글이 맞서는 압박

법원칙과 도덕적 논증을 인정하면 하트의 승인 규칙과 재량론이 무너지는 듯하다. 그러나 법의 내용을 도덕적으로 가장 건전한 해석에 맡기면 법의 사회적 원천과 권위적 매개 기능이 사라지는 듯하다. 하트의 *Postscript*는 이 두 방향의 압박 사이에서 본문의 이론을 방어하고 일부를 수정한다.

## 읽기 순서

1. [Dworkin·Raz 비판 사전 가이드]({{ site.baseurl }}/reading-guides/hart-critics-prep/)에 제시된 필수 발췌를 먼저 읽는다.
2. 공통 범위 밖의 배경은 [조별 보충 독서 가이드]({{ site.baseurl }}/reading-guides/hart-critics-divided/)에서 담당 범위를 확인한다.
3. 비판자의 주장과 하트가 후기에 재구성한 주장을 구별한다.
4. 하트의 문단을 `수용`, `반박`, `한정`, `수정` 중 하나로 표시한다.
5. 하트의 최종 입장이 드워킨과 라즈 어느 쪽과 가까운지 쟁점별로 다시 판정한다.

## 비판과 응답을 찾기 위한 교차 지도

| 먼저 확인할 비판 | Postscript에서 추적할 쟁점 | 대조할 질문 |
| --- | --- | --- |
| 드워킨 pp. 22-28의 규칙/원칙 구별 | 규칙과 원칙의 차이를 하트가 어떤 기준으로 다시 설명하는가 | 하트는 드워킨의 논리적 구별을 반박했는가, 약화했는가? |
| 드워킨 pp. 28-31의 기존 권리·강한 재량 비판 | 어려운 사례의 기존 법, 이유, 법창출을 하트가 어떻게 구분하는가 | 어려운 사례에는 정말 기존 권리가 없었는가? |
| 드워킨 pp. 39-45의 승인 규칙 비판 | 원칙의 지위와 승인 기준의 관계를 하트가 어떻게 설정하는가 | 복합적인 제도적 뒷받침을 승인 규칙이 충분히 포착하는가? |
| 라즈의 원천·편입·정합성 테제 | 도덕 기준의 편입과 사회적 원천을 하트가 어떻게 양립시키는가 | 편입된 도덕 기준은 법의 권위적 매개 기능을 약화하는가? |
| 라즈의 법 내용과 재판 이유 구별 | 법이 침묵할 때 판결 이유와 법의 내용이 어떻게 관계하는가 | 법이 아닌 도덕적 이유로도 판결이 정당화될 수 있는가? |

## 여섯 구간에서 물을 질문

| 구간 | 중심 질문 | 읽으며 표시할 대립 |
| --- | --- | --- |
| 방법론 | 법이론은 기술적인가 해석적인가? | 기술/평가, 이해/지지 |
| 실증주의의 성격 | 하트는 의미론적·명백한-사실 이론가인가? | 단어 의미/법의 근거, 명백한 사실/논쟁적 기준 |
| 규칙의 실천 이론 | 사회적 규칙은 단순한 부합 실천인가? | 부합/수용, 관행적 이유/독립된 이유 |
| 법원칙 | 원칙을 인정하면 승인 규칙이 무너지는가? | 규칙/원칙, 계보/제도적 뒷받침 |
| 법과 도덕 | 도덕 기준은 법적 유효성 기준이 될 수 있는가? | 우연적 편입/필연적 연결 |
| 재량 | 어려운 사례에서 판사는 법을 발견하는가 만드는가? | 기존 법/새 법, 제약/자의성 |

## 중요한 범위 제한

공통 필수 발췌는 *Postscript*의 모든 논쟁 배경을 포함하지 않는다. 다음 쟁점은 초기 「규칙의 모델 I」만으로 설명해서는 안 된다.

- 의미론적 독침과 이론적 의견불일치
- 관행주의와 통합성으로서의 법
- 규칙의 실천 이론에 대한 「규칙의 모델 II」의 비판
- 전해석적 법과 해석적 법의 구별
- 후기 드워킨의 구성적 해석과 정합성 이론 전체

이 쟁점들은 『법의 제국』과 후속 논문을 위한 별도 독서 경로다. 사전 수업에서는 공통 발췌가 실제로 뒷받침하는 주장과 하트가 후기 저작들에서 끌어오는 주장을 구별한다.

## 본문에서 표시할 대목

- 하트가 드워킨의 비판을 타당하다고 인정하는 문장
- 하트가 자신에게 잘못 귀속된 이론을 부인하는 문장
- 승인 규칙에 도덕 기준이 들어올 수 있다고 말하는 문장
- 규칙의 실천 이론의 적용 범위를 축소하는 문장
- 규칙과 원칙의 차이를 정도 차이라고 말하는 문장
- 판사의 법창출을 인정하면서도 자의성을 부정하는 문장

## 피해야 할 성급한 결론

- *Postscript*에 제시된 드워킨의 주장을 곧 하트의 주장으로 읽지 않는다.
- 하트가 법원칙을 인정했다는 이유만으로 드워킨의 법이론을 받아들였다고 단정하지 않는다.
- 연성 실증주의를 법적 유효성이 언제나 도덕 판단에 달린다는 주장으로 바꾸지 않는다.
- 라즈를 하트의 단순한 방어자로 읽지 않는다. 라즈는 하트의 편입 테제도 비판한다.
- 재량을 판사의 개인적 선호나 무제한 선택과 동일시하지 않는다.

## 토론 질문

1. 하트는 드워킨의 규칙/원칙 구별을 실제로 반박했는가, 아니면 경계를 흐렸을 뿐인가?
2. 원칙의 법적 지위를 식별하는 기준이 복합적이어도 그것을 승인 규칙이라고 부를 수 있는가?
3. 도덕 기준을 편입한 승인 규칙은 라즈가 요구하는 권위의 매개 기능을 수행할 수 있는가?
4. 하트의 간극적 법창출론은 드워킨의 기존 권리와 소급성 비판에 충분히 답하는가?
5. 하트의 중간 위치는 독립적으로 안정적인가, 아니면 쟁점에 따라 드워킨 또는 라즈 쪽으로 이동하는가?
