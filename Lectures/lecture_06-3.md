# 제6장 제3절 법체계의 병리학 분석

---

### 1. 필자가 대결하려는 입장 vs. 하트의 반론 (논변 구조)

| 대결하려는 입장(잠재·명시)            | 하트의 반론(주요 논증)           | 설명       |
| ---------- | ---- | ---------------------------------- |
| **(A)** ‘법체계의 존재 여부는 단순히 *사실적 복종* 여부에 달렸다’ ― 복종이 사라지면 곧바로 법체계도 소멸한다.               | 법체계의 존재를 말할 때는 **① 공적(official) 부문**과 **② 사적(private) 부문**의 *복합적‧합치적 관행*이 전제된다. **일시적·부분적 불일치(즉, 병리학(pathology))는 곧바로 소멸을 뜻하지 않는다.**                           | ‘법체계 존재’라는 외부적 사실진술은 폭 넓은 범주이므로, 단기간의 혼란·불복종만으로는 “소멸” 판단이 성립하지 않음을 강조. |
| **(B)** ‘법 내부의 규정(예: 회복 후 소급법)이 과거의 사실을 “정의”하면, 이는 외부적 사실진술과 모순된다.’                | **외부적 사실진술**(sociological, descriptive)과 **내부적 법진술**(규범적·소급적)은 *기능과 논리적 지위*가 다르므로 모순이 아니다.                            | 동일 사태를 두 개의 시선으로 말한 것일 뿐 ‘사실(False) vs 법(Correct in law)’ 구별이 가능.      |
| **(C)** ‘식민지의 독립 과정은 규칙(규범)론으로 설명할 수 없다. 역사적 연속성과 단절이 뒤섞여 있으므로 “새 법체계”의 기준이 모호하다.’ | **최종적 승인규칙(rule of recognition)**이 “어느 입법·판결을 법으로 받아들이는가?”에 대한 *실제 관행적 수용*‧*법관의 사용*에 근거해 변동할 수 있음을 보임으로써, **법체계의 ‘발생학(embryology)’을 규칙론으로도 충분히 포착함**. | 규범적 권위의 ‘지역적 뿌리(local root)’가 생기면 새 체계로 전환된다는 점을 보여줌.                   |
| **(D)** ‘공적 부문 내부 불일치(법관 분열)는 규칙(특히 rule of recognition) 개념을 무너뜨린다.’               | 최종 승인규칙조차 **개방적 구조(open texture)**를 지니며, 한시적·부분적 분열은 “동일 법체계”를 완전히 부정하지 않는다. 단, 장기화·전면화되면 해체 위험이 현실화됨을 인정.        | 규칙 개념이 현실의 불확정성‧경계 사례를 포괄할 수 있음을 반박적으 로 시연.                            |

### 2. 주요 예시가 논증에 기여하는 방식

| 예시 / 사례                 | 어떤 논증 포인트를 뒷받침? | 기여 방식                        |
| ------------------ | --------------- | ------------- |
| **① 혁명 · 점령 · 무정부 상태** (p. 118)                        | A(에 대한 반론)    | ‘복종 단절 = 즉각적 소멸’이 아님을 보여주는 **병리학(pathology) 사례군**: 서로 다른 교란 양상을 열거하여 ‘부분적 불일치’의 스펙트럼을 제시.  |
| **② 망명정부 복귀 후 소급법** (p. 119)                           | B   | *자기지시적(self-referential)* 법규가 과거를 ‘간주(deemed)’하는 상황을 통해 **사실진술 vs 법진술**의 논리적 상이성을 실감나게 제시. |
| **③ 영국 의회가 “차르 시대 러시아법이 여전히 유효”라고 선언할 경우** (p. 120)    | B            | 극단적 가상사례로 법진술의 효력이 ‘선언된 관할권 내부(영국 법원)’에 국한됨을 부각, 사실과의 불충돌성을 직관적으로 설명.                      |
| **④ 식민지의 단계적 독립(코먼웰스 역사)** (p. 120-122)                | C            | ‘부모-식민지’ 관계가 **최종 승인규칙의 이동**으로 서서히 변형되는 과정을 ‘발생학(embryology)’ 메타포로 묘사, 규칙론의 설명력을 강화.       |
| **⑤ 봉쇄되지 않은 규범 충돌: *Harris v Dönges* 사건** (p. 122-123) | D            | 입법부와 사법부가 **상호 무효 선언**을 반복했던 실제 사례로, <br>– 최종 승인규칙이 “분열 중”일 때도 다수의 일상적 법운영은 지속됨 <br>– 그러나 장기화 시 시스템 붕괴 위험 → ‘경계 사례’를 시각화. |

---

### 3. 정리 — 이 섹션의 설계

1. **‘병리학’과 ‘발생학’**이라는 두 축을 배치하여
   *법체계 존재론*이 **단선적‧정태적 모델**이 아님을 강조한다.

2. 각 사례는 *추상 논변*을 **경계 사례(최대 긴장점)**로 밀어붙여 → 규칙 개념이 실제로도 작동함을 보여주는 **귀납적 증거** 역할을 한다.

3. 전체적으로 하트는

   * **외부적 사실진술**과 **내부적 법진술**을 구별하고,
   * **최종 승인규칙의 관행적 수용**이 법체계 동일성의 핵심 조건임을 방어하며,
   * 규칙 개념이 갖는 **개방적 구조** 때문에 오히려 현실의 불확실성과 변화를 설명할 수 있다고 재반박한다.

> 따라서 이 섹션은 “규칙-중심 법개념은 현실의 무질서·변동을 포착하지 못한다”는 일련의 비판에 대해, **경계·전이 상황**을 면밀히 해부함으로써 규칙론이 갖는 설명력과 탄력성을 실증적으로 옹호하는 설계로 구성되어 있다.
