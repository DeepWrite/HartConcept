## I. 「V. LAW AS THE UNION OF PRIMARY AND SECONDARY RULES」 1절(“A Fresh Start”) — 문제제기 구조 분석

| 구분               | 원래 이론·주장                                                    | 암묵적 추론·귀결                                            | 하트의 비판(제4장 요약)                                                                                                                                                   | 5장 초두에서 제기하는 **핵심 탐구 과제**                                                               |
| ---------------- | ----- | ------------------------- | ------------------------- | ------ |
| **I. 법의 본질**     | **(O1)** “법은 궁극적으로 **주권자의 강제 명령(coercive orders)** 에 불과하다.” | → 모든 법규(형벌·사법·사적 권한·관습 등)는 명령 + 위협 형태로 환원될 수 있어야 한다. | - 자가적 효력(self-applying) 형벌법 규정 등, *법이 입법자 자신에게도 적용*되는 현상 미설명.<br>- 권한부여규정(입법·계약·재판)이 명령으로 환원되면 “위협” 성격이 사라져 *부조리* 초래.<br>- 명문화되지 않은 관습·관례 규정은 ‘명령’ 모델로 기원 설명 불가. | **Q1** ‘모든 법=명령’ 명제는 왜 실패했는가? → 법을 구성하는 **“규칙(rule)”** 개념 자체가 누락되었기 때문임을 보일 것.          |
| **II. 의무·복종 개념** | **(O2)** “의무·의무위반은 단지 **제재 위험**에 대한 *예측*을 의미한다.” (예: 건맨 사례) | → 법적 의무는 ‘불복종 시 불이익을 당할 가능성’으로 충분히 정의된다.             | - **내적 시각(internal point of view)** 무시: 규칙을 *이유·정당화*로 삼는 행위자들의 태도 설명 실패.<br>- 실제로는 제재 위험이 0에 근접해도 ‘의무가 존재’한다고 말할 수 있음.                                           | **Q2** 의무(또는 규범적 구속력)가 *단순 예측*으로 환원될 수 있는가? → **내적 시각**을 포함해야 풍부한 규범 개념을 설명 가능함을 드러낼 것. |
| **III. 법체계의 구조** | **(O3)** “주권자는 (a) 습관적 복종을 받고 (b) 법적으로 무제한(illimitable)이다.” | → 입법권의 **연속성·지속성·한계** 문제는 (a)(b)로 자동 해결된다.           | - 입법자 교체 시 *복종 습관*만으로는 법적 연속성 설명 불가.<br>- 과거 입법의 존속·생존성(persistence) 설명 실패.<br>- 현대 국가의 헌정·연방적 한계와 상충.                                                           | **Q3** 입법권의 연속·지속·한계는 **1차·2차 규칙(primary/secondary rules)** 구조로만 설명될 수 있음을 입증할 것.       |

---

#### 5장이 설정하는 새로운 연구 프로그램

1. **실패 진단 → 해결의 실마리**

   * 실패 원인은 “명령·습관·위협” 요소 속에 **‘규칙’** 개념이 결여되어 있다는 점.
   * 특히 법을 이해하려면 **① 행위 규율(1차 규칙)과 ② 규율 자체를 제정·변경·인증·심판하는 2차 규칙**을 구분·결합해야 함.

2. **주요 테제(예고)**

   1. **법 = 1차 규칙(duty-imposing) ∪ 2차 규칙(power-conferring)** 의 *통합체*.
   2. 이 통합 구조가 **의무·권한·효력·근원·입법·사법** 등 난해 개념을 가장 효과적으로 설명한다.
   3. ‘내적 시각’은 2차 규칙이 작동할 때 더욱 다층화되므로, 법 이론은 이를 필수 분석 단위로 삼아야 한다.

3. **따라서 …**

   * 5장은 \*\*“규칙의 결합 구조”\*\*를 중심으로 새 틀을 제시하며,
   * 이어지는 장들(Ⅵ～Ⅸ)에서 **법적 유효성·주권·공권력·도덕성과의 관계**를 재정식화한다.

## II. 「A Fresh Start」(§1–3) — 핵심 테제·논증 매트릭스

| 번호      | **제시·비판된 테제**                                  | **옹호·공격 논거**<br>(명시 + 함축)                                                                                                                                                                                                                                      | **귀결·대안 테제**                                                   |
| ------- | ---------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| **T-1** | **명령모델:** “법은 주권자의 위협적 명령(coercive orders)이다.” | 1. *자가적 효력* : 형사법은 입법자 자신에게도 적용 → ‘타인에게만 명령’과 불일치.<br>2. *권한부여 규정* : 입법·계약·소송능력 등은 ‘위협’ 없이 권한을 **부여**함 → 명령으로 환원 시 모순.<br>3. *비-처방적 생성* : 관습·선례 등은 ‘명시적 명령’ 없이 발생.<br>4. *연속·지속성* : 입법교체·과거법 존속 설명 실패.<br>⇒ 보조 기제(묵시명령, duty-fragment 이론 등) 투입했으나 실제 언어·관행 왜곡. | **T-A1** → **‘명령’ 요소만으로는 규범적 다면성 설명 불가**; ‘규칙(rule)’ 개념 도입 필요. |
| **T-2** | “의무(duty)란 곧 제재를 당할 **예측**이다.” (건맨 사례 일반화)     | 1. ‘obliged’ ↔ ‘has an obligation’ 구별: 후자는 믿음 · 제재 위험 여부와 **무관**하게 성립.<br>2. 제재 0%라도 ‘의무’ 서술 무모순(도피·뇌물 사례).<br>3. 의무 발언의 **기능**은 예측이 아니라 “규칙에 해당함”을 지시(=내적 시각).                                                                                                | **T-A2** → 의무는 **사회적 규칙 + 내적 정당화**를 전제하는 규범적 개념.               |
| **T-3** | “규칙은 모두 주권자·관료에게만 향한다.”                        | (함축) 시민 행위의 권리·의무 언어를 설명 못함 → “게임 규칙이 심판 지시일 뿐”이라는 오류.                                                                                                                                                                                                         | **T-A3** → 규칙은 **일반 행위자**가 내적으로 수용·적용함을 설명해야 함.                |
| **T-4** | “주권자는 법적 제한 불가·습관적 복종의 대상.”                    | 근거: 습관·위협 분석 한계(Ⅳ장). → 근세 국가의 헌법·연방 제한 사례들과 배치.                                                                                                                                                                                                                | **T-A4** → 입법권의 **권한·한계**는 *2차 규칙*으로 이해해야 설명 가능.               |

## 5장 제안: **“법 = 1차 · 2차 규칙의 결합”**(Master-Thesis)

| 구분                   | **1차 규칙(Primary Rules)**                                        | **2차 규칙(Secondary Rules)**                                                                        | **설명·정당화 논리**                                               |
| -------------------- | --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| **내용**               | 행위 **의무·금지** 부과                                                 | 규칙 자체를 **인식·변경·심판**                                                                               | –                                                           |
| **기능적 문제** (단독 적용 시) | **① 불확실성** (규칙 확인 불가)<br>**② 정체성** (변경 불가)<br>**③ 비효율** (분산 제재) | **i) Rule of Recognition**<br>**ii) Rules of Change**<br>**iii) Rules of Adjudication (+ 제재 규정)** | 각 2차 규칙은 1차 규칙의 결함을 *정교하게 보완* → ‘전(前)-법(custom)’에서 ‘법’으로 도약 |
| **내적 시각 확장**         | → ‘의무’·‘권리’ 등 최소 규범어 사용                                         | → ‘유효성’·‘입법’·‘사법’·‘권한’ 등 복합 규범어 생성                                                                | **규칙 수용**을 통해 법적·정치적 개념망 형성                                 |

## 층위별 상세 논증 흐름

1. **실증적 반례 제시** → T-1, T-4 붕괴

   * *자가적 효력·권한부여·관습·헌정제약* 사례들은 명령모델로는 설명 불가.
2. **개념 분석** → T-2 반박

   * ‘obliged’ vs ‘obligation’ 구별·내적 시각(규칙-이유 구조) 제시.
3. **규범 구조 재구성** → Master-Thesis 정립

   * 1차 규칙만의 ‘3대 결함(uncertainty·static·inefficiency)’ → 2차 규칙 필요성.
4. **제도적 귀결**

   * Rule of Recognition ⇒ *유효성*·*법원(法源)* 개념.
   * Rules of Change ⇒ *입법*·*사적 법률행위* 이해.
   * Rules of Adjudication ⇒ *사법권·제재 집중* + 판례가 ‘법원’이 되는 메커니즘.
5. **분석적 효율성 선언**

   * 결합 구조가 의무·권리·주권·국가·권위 개념을 가장 경제적으로 설명.
   * ‘1차＋2차 규칙’은 \*\*“법체계의 심장부”\*\*이나, 주변부(국제법·관습 등)는 후속장서 추가 조정 예정.

> **종합:** §1–3은 주권-명령 모델의 한계를 실증·개념 양면에서 해부하고, \*\*“규칙적 결합”\*\*을 새로운 이론적 엔진으로 제시함으로써, 이후 장(Ⅵ\~Ⅸ)의 상세 전개를 위한 전제 틀을 제공한다.
