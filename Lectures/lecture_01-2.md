# 후기(POSTSCRIPT) 부분 참고

## 1. 법이론의 성격을 둘러싼 논쟁

| 도전 과제                    | 하트의 방어 논증                            |
| -------------- | ---------------- |
| **(1) 법이론의 목적**          |      |
| 드워킨은 “법이론은 평가적·정당화 지향적이어야 하고, 판결의 일반 이론이어야 한다”고 주장.      | 하트는 “법이론은 기술적·묘사적(descriptive) 작업”으로서, **법의 일반 형태와 구조**를 도덕적·정당화적 관점과 무관하게 명료히 밝히는 것이 선행되어야 한다고 맞선다. |
| **(2) 내적 관점 vs. 외적 관점**  |      |
| 드워킨은 “법이론은 반드시 법 참여자의 내적 관점을 포착해야” 하며, 외적 기술은 무의미하다고 비판. | 하트는 “외적 관찰자도 ‘내적 관점(법 규범을 스스로 지침으로 삼는 태도)’을 충분히 이해·기술할 수 있다”며, 기술적 접근이 내적 관점을 배제하지 않음을 강조.           |

---

## 2. 법실증주의(Positivism)에 대한 공세

| 도전 과제   | 하트의 방어 논증                |
| ----------------------------- | -------------------------- |
| **(1) ‘명백한 사실 실증주의’의 오해**               |                          |
| 드워킨은 하트를 “단지 ‘law’의 의미에서 출발해, 법의 내용 식별 기준을 역사적 사실에만 의존하는 의미론적 이론가”로 폄하. | 하트는 “승인규칙(rule of recognition) 이론은 ‘law’의 어휘 의미로부터가 아니라, **법을 식별하는 사회적 근원**(입법·판례·관습 등)에 대한 묘사에서 출발”하며, “도덕 가치도 포함 가능한 ‘연성 실증주의(soft positivism)’”임을 반박. |
| **(2) 해석주의적 재구성**                       |                          |
| 드워킨은 하트의 실증주의를 ‘관행주의적 해석 이론’으로 고쳐 쓰며 “법은 강제의 정당화라는 목적을 갖는다”고 몰아붙임.      | 하트는 “법의 목적을 강제 정당화로 환원할 수 없으며, 법 이론은 그 목적을 탐구하지 않는다”며, \*\*법의 기능(가이드·비판 기준 제공)\*\*에 집중하는 자신의 입장을 재확인.                    |

---

## 3. 규칙(rules) vs. 원칙(principles)

| 도전 과제                    | 하트의 방어 논증            |
| -------------- | ---------- |
| **(1) 법적 원칙의 간과**        |                      |
| 드워킨: “하트는 법을 오직 ‘전부-무(all-or-nothing)’ 방식의 규칙만으로 본다.”    |                      |
| → 이는 **비결정적(non-conclusive)** 성격을 지닌 법적 원칙의 중요성을 무시한 것.  | 하트: “규칙과 원칙은 이분법적 구분이 아니라, **결정성의 정도 차이**일 뿐.”       |
| • “거의 결정적인 규칙” vs. “조언적·방향 제시적 원칙”이라는 구분 가능              |                      |
| • **가변적 법적 기준(variable standards)** 개념으로 원칙 포함 가능        |                      |
| **(2) 승인규칙 vs. 해석기준**    |                      |
| 드워킨: “법적 원칙은 **승인규칙(rule of recognition)** 으로 식별될 수 없다.” |                      |
| → 따라서 하트의 실증주의는 법의 실제 구조를 포착하지 못함.                       | 하트: “많은 원칙은 **형식적 근원(pedigree)** 을 통해 승인규칙으로 식별 가능.” |
| • 해석 기준도 넓은 의미의 **승인규칙 구성요소**로 포섭 가능                     |                      |

## 4. 법과 도덕의 관계

| 도전 과제                          | 하트의 방어 논증 |
| -------------------- | --------------------- |
| **(1) 권리·의무의 도덕적 근거 필수론**      |           |
| 드워킨은 “법적 권리는 도덕적 권리의 일종”이라, 실증주의는 법 권리·의무를 무도덕적 근거에서 인정한다고 비난. | 하트는 “법적 권리·의무는 **사회적 근원**(입법·판결 등)으로부터 자율적으로 발생”하며, 도덕과는 **우연적 연관성**만 있을 뿐 개념적 필연은 아니라고 방어.               |
| **(2) ‘해석적 법’ vs. ‘기술적 법’**    |           |
| 드워킨은 “법은 항상 도덕적 정당화를 수반하는 해석적 의미”라, 하트식 기술적 법 이론을 부정.          | 하트는 “법을 도덕과 무관하게 식별할 수 있는 ‘기술적 법’ 개념도 타당하며, 악명 높은 체계조차 ‘전(前)해석적 법(pre-interpretive law)’으로 인정할 수 있다”고 반박. |

---

## 5. 사법적 재량(Judicial Discretion)

| 도전 과제                    | 하트의 방어 논증     |
| ------ | ---- |
| **(1) 법 창출 권한 부정**       |               |
| 드워킨: “난해한 사건(hard cases)에도 항상 유일한 ‘정답’이 존재한다.”           |               |
| → 판사는 법을 **발견**할 뿐, 결코 **창출**하지 않는다.                     | 하트: 법은 본질적으로 **부분적으로 불완전(indeterminate)** 하다. |
| • 명확한 규칙이 없는 사안에서는, 판사가 **제도적 제약 하에서** **재량**을 행사해 **간극(interstice)을 메우는 법을 창출**한다.      |               |
| • 이 과정에서 판사는 “**양심적 입법자(conscientious legislator)**”로서 판단하지만, 이는 **입법권과 구별되는 제한적 역할**이다. |               |
| **(2) 민주적 정당성 문제**       |               |
| 드워킨 계열: 사법 재량은           |               |
| • 입법되지 않은 법의 창출이므로 **비민주적**이며,                           |               |
| • 소급효를 가지므로 **불공정**하다.   | 하트: 제한된 사법 재량은 **불가피한 제도적 기능**이다.             |
| • 입법부에 회부하기 어려운 사안들에 대응하기 위한 **제도적 장치**로 기능.             |               |
| • 현대 민주주의는 다양한 **위임(delegation)** 을 수용하고 있으며,            |               |
| → **사법적 입법권도 그 일부**로 받아들여질 수 있다.                         |               |


---

### 결론

후기에서 하트는, 드워킨을 비롯한 비판자들이 자신의 **기술적·일반적 법이론**(positivist descriptive jurisprudence)을 “의미론적 오류”, “평가적 이론으로의 오독”, “판사의 법 창출 부정” 등으로 몰아붙인 데 대해 차례차례 반박하면서,

1. **법 이론은 우선 ‘법(law)’의 객관적 구조와 작동 방식을 기술·명료화해야** 하고,
2. **도덕·정당화 문제는 그 기술적 기초 위에서 이어지는 별도의 과제**임을 재확인한다.

이로써 하트는 “법이론은 평가 이론만이 아니라, 묘사 이론도 필수적”이라는 자신의 입장을 마지막까지 견지하며, 법철학의 **‘기술(descriptive)’과 ‘해석(evaluative)’** 양축이 상호 보완적으로 작동해야 함을 강조한다.
